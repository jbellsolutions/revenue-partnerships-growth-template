# Revenue Partnerships Growth — reusable agent template

A demand-generation system for growing businesses through affiliates and partner relationships. One accountable Growth Director uses 11 partner families, 67 subcategories and 339 partner-type profiles. Dream 100 and Dream 500 are relationship tiers.

## Start here

1. Use this GitHub template to create a **private** client repository.
2. Read [INSTALL.md](INSTALL.md), [skills and plugins](CAPABILITIES.md), [operating checklists](OPERATIONS.md), and [workforce integration](blueprints/revenue-partnerships/WORKFORCE.md).
3. Complete [client/program.example.json](client/program.example.json) privately. Preserve unknown terms as unknown.
4. Run `python3 scripts/verify.py` and `python3 -m unittest discover -s tests`.
5. Install a separate Hermes profile on an existing approved computer. Do not clone another client's sessions, credentials or partner records.

[Explore all 339 types](blueprints/revenue-partnerships/explorer.html) locally in your browser. Profiles are generated dossier seeds; they are not 339 running agents or verified prospects.

The bundled relationship MCP supports private cards, context and drafts. It has no send, approval, payment or CRM dispatch tools. Attio and ClickUp integration requirements are specified; production synchronization adapters and System One role/queue adapters remain integration work. Existing adapters must pass the stated acceptance gates before being called live.

Public source material and generic playbooks only. Actual offers, contracts, contacts, account IDs, deployment inventory, memories and receipts belong in a private client project. MIT license; reused Affiliate Manager code retains its original notice and pinned provenance in SOURCES.json.
