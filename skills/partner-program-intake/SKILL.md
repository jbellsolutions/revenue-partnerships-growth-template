# Partner Program Intake

Capture business, paid/free offers, customer ICP, partner ICP, approved claims, exclusions, accepted commercial models, attribution rules, authority, account identities and budget. Separate observed pages from owner-approved facts. Save the private versioned program card; list unknown fields and exactly which operations they block. Complete when an owner-reviewed program version and readiness disposition exist.

Read AGENTS.md, the private program card and OPERATIONS.md for authority and receipt requirements. Secrets stay in the client secret store. Stop affected work when context, authority or connection evidence is missing. Report prepared versus completed work accurately.
