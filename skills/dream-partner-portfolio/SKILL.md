# Dream Partner Portfolio

Treat Dream tiers as cross-taxonomy relationship tiers. Review existing ownership and communication before any new ask. Create a sourced dossier: customer overlap, trust, access path, strategic value, first collaboration and relationship history. Recommend tier with explicit evidence; the owner assigns it. Owner writes Dream outreach unless the private program explicitly changes that rule. Complete with one relationship owner, next action, due date and a realistic activation milestone.

Read AGENTS.md, the private program card and OPERATIONS.md for authority and receipt requirements. Secrets stay in the client secret store. Stop affected work when context, authority or connection evidence is missing. Report prepared versus completed work accurately.
