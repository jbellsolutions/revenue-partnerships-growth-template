# Complete partner taxonomy

Source snapshot: 2026-10-09. 11 families / 67 subcategories / 339 types.

## F1 Affiliates — 41 types

Affiliates are independent publishers, creators, list owners or businesses who promote an offer to their audience and are paid only on a tracked outcome (sale, lead, call, install or signup), attributed by link, code or platform.

### F1.A Content & editorial publishers

- **F1.A.1 Niche blogger / SEO affiliate site** — Topic site ranking for buyer-intent searches; reference model: CPS %.
- **F1.A.2 Review site** — Single-product or category reviews; reference model: CPS % or CPA.
- **F1.A.3 Comparison / "best X" / "X vs Y" site** — Listicles and head-to-head pages; reference model: CPS %, sometimes placement fee.
- **F1.A.4 Mass-media commerce desk** — Newspaper or magazine shopping desk; reference model: Flat fee + commission.
- **F1.A.5 B2B software review / list directory** — Software directories and list sites; reference model: Recurring % or CPA.
- **F1.A.6 Long-form creator-affiliate** — YouTube or podcast creator paid only on tracked commission; reference model: CPS %, code attribution.
- **F1.A.7 Educator / course creator affiliate** — Teachers linking tools inside lessons; reference model: Recurring %.

### F1.B Deal & incentive publishers

- **F1.B.1 Coupon / voucher code site** — Code aggregators; reference model: CPS + tenancy fees.
- **F1.B.2 Deal community / forum** — User-voted deal boards; reference model: CPS.
- **F1.B.3 Cashback portal** — Shares commission back to shoppers; reference model: CPS + placement fee.
- **F1.B.4 Loyalty / points / miles program** — Airline, hotel or retail points malls; reference model: CPS + tenancy.
- **F1.B.5 Card-linked offer platform** — Offers triggered by bank-card spend; reference model: Per transaction.
- **F1.B.6 Browser extension** — Auto-applies codes or cashback; reference model: CPS.
- **F1.B.7 Virtual incentive / reward app** — In-game currency or survey rewards; reference model: CPA.
- **F1.B.8 Affinity / closed user group** — Gated audiences such as students, military, employees; reference model: CPS.

### F1.C Performance & paid-traffic affiliates

- **F1.C.1 Media buyer** — Buys paid social, native or display to drive offers; reference model: CPA.
- **F1.C.2 PPC / search affiliate (incl. trademark-plus)** — Bids on search terms, branded only with permission; reference model: CPA / CPS.
- **F1.C.3 Domain parking** — Monetizes parked domains; reference model: CPC.
- **F1.C.4 Retargeting partner** — Re-engages site visitors; reference model: CPC / CPM.
- **F1.C.5 Comparison shopping engine** — Price-comparison feeds; reference model: CPC / CPS.
- **F1.C.6 Mobile / app-install & SMS partner** — App installs, SMS offers; reference model: CPI / CPA.
- **F1.C.7 Pay-per-call publisher / call network** — Drives qualified inbound calls; reference model: Per qualified call.
- **F1.C.8 Lead-gen publisher (quiz funnels, co-reg)** — Collects and sells leads; reference model: Per lead.

### F1.D Email & list owners

- **F1.D.1 Owned-newsletter affiliate** — Newsletter linking offers on commission; reference model: CPS / CPA.
- **F1.D.2 Rented / shared list mailer** — Mails third-party lists on performance; reference model: CPA or per send.
- **F1.D.3 Email lead-gen affiliate** — Captures leads via email; reference model: Per lead.
- **F1.D.4 Email retargeting partner** — Re-mails abandoners on the brand's behalf; reference model: CPS.

### F1.E Aggregators & sub-networks

- **F1.E.1 Sub-affiliate network** — Houses hundreds or thousands of small publishers; reference model: Pass-through commission less margin.
- **F1.E.2 CPA network** — Performance network of media buyers; reference model: CPA.
- **F1.E.3 Creator monetization layer** — Aggregates creators' links; reference model: Pass-through.

### F1.F Technology & commerce-enablement partners

- **F1.F.1 Conversion-tech widget / plug-in** — On-site tools that drive conversions; reference model: CPS / rev share.
- **F1.F.2 Checkout / cart-abandonment tool** — Recovers carts; reference model: CPS.
- **F1.F.3 Shopping assistant / AI answer surface** — Assistants that recommend products; reference model: CPS.
- **F1.F.4 Registry platform** — Wedding and baby registries; reference model: CPS.

### F1.G Community & micro-creator affiliates

- **F1.G.1 Community owner affiliate** — Skool, Discord, Facebook group or Reddit owner linking offers; reference model: Recurring %.
- **F1.G.2 Commission-only micro-creator** — Small social creator on commission, no fee; reference model: CPS, code attribution.

### F1.H B2B & professional affiliates

- **F1.H.1 B2B SaaS affiliate (consultant, blogger, educator)** — Professionals recommending software; reference model: Recurring %.
- **F1.H.2 Agency-as-affiliate** — Agency that recommends but does not resell; reference model: Recurring %.
- **F1.H.3 Freelancer / implementer affiliate** — Solo implementers linking tools; reference model: Recurring %.

### F1.I Customer & alumni affiliates

- **F1.I.1 Customer affiliate** — Customer paid cash commission for promoting to an audience; reference model: Cash %.
- **F1.I.2 Graduate / alumni affiliate** — Course or certification graduate promoting via link; reference model: Cash %.

## F2 Influencers & Creators — 24 types

Influencers & Creators are individuals paid at least partly in cash, product, retainer or equity for their content, endorsement or creative voice.

### F2.A Sponsored social content

- **F2.A.1 Sponsored post / video** — Feed post, Reel, TikTok, Short, Story, carousel, X or FB post, Pin; reference model: Flat fee.
- **F2.A.2 Product seeding / gifting** — Unconditional product send; reference model: Product only.
- **F2.A.3 Gifted-for-post** — Product plus a posting agreement; reference model: Product + small fee.
- **F2.A.4 Account takeover** — Creator runs the brand's account for a day; reference model: Flat fee.
- **F2.A.5 Live-stream integration** — Reads, overlays or sponsored streams on Twitch, YouTube Live or TikTok Live; reference model: Per stream or per hour, priced on concurrent viewers.
- **F2.A.6 Event / experience invite** — Press trips, launches, brand trips; reference model: Hosted + fee.
- **F2.A.7 Creator-run contest / giveaway** — Giveaway on the creator's channel; reference model: Flat fee + prize.

### F2.B UGC & content creation

- **F2.B.1 UGC ad creative** — Testimonial, unboxing, demo and hook variants for the brand's ads; reference model: Per asset.
- **F2.B.2 Creator content licensing** — Brand licenses an existing organic post; reference model: Usage-rights fee.
- **F2.B.3 Raw footage / photo asset pack** — Unedited footage or photos; reference model: Per pack.
- **F2.B.4 AI / virtual creator content** — Synthetic avatars or virtual influencers; reference model: Flat fee.

### F2.C Creator-handle paid amplification

- **F2.C.1 Meta Partnership Ads** — Ads run from the creator's handle via an authorization code; reference model: Monthly whitelisting fee.
- **F2.C.2 TikTok Spark Ads** — Boost an organic creator video with a Spark code; reference model: Licensing fee or higher Shop commission.
- **F2.C.3 YouTube creator partnerships boost** — Creator video run as Shorts or in-stream ads; reference model: Fee + media.
- **F2.C.4 LinkedIn Thought Leader Ads** — Sponsoring a creator's LinkedIn post; reference model: Surcharge on post fee.
- **F2.C.5 Dark posting** — Ads from the creator's handle that never appear in the organic feed; reference model: Whitelisting fee.

### F2.D Long-term creator relationships

- **F2.D.1 Brand ambassador** — Exclusive 3-12 month relationship, 4-12 posts/month; reference model: Monthly retainer + exclusivity.
- **F2.D.2 Creator advisory board / creator-in-residence** — Creators who shape product and content; reference model: Retainer or equity.

### F2.E Creator commerce

- **F2.E.1 TikTok Shop affiliate** — Creators sell via Shop, through open or targeted collabs; reference model: Commission, sometimes + flat fee.
- **F2.E.2 Amazon Influencer / LTK storefront creator** — Storefront curation; reference model: Commission, sometimes + fee.
- **F2.E.3 Livestream shopping host** — Sells live on TikTok Live, Whatnot or Amazon Live; reference model: Commission + fee.

### F2.F Co-creation & creator IP

- **F2.F.1 Collab drop / co-created product** — Limited edition with a creator; reference model: Royalty or rev share.
- **F2.F.2 Creator equity / co-owned brand** — Equity or advisor options; reference model: Equity (often 1-yr cliff, 4-yr vest).
- **F2.F.3 Creator name / likeness licensing** — Creator IP on packaging or ads; reference model: Royalty + advance.

## F3 Sponsorships — 35 types

A sponsorship is a paid placement (cash or in-kind) inside media, a property or an event that someone else owns and controls.

### F3.A Newsletter & community media

- **F3.A.1 Newsletter primary placement** — Top ad unit in an issue; reference model: CPM on opens or flat.
- **F3.A.2 Newsletter secondary placement** — Mid-issue unit; reference model: Share of primary.
- **F3.A.3 Classified / footer placement** — Short text unit; reference model: Share of primary.
- **F3.A.4 Dedicated send** — Whole issue for one sponsor; reference model: Multiple of primary.
- **F3.A.5 Ad-network placement** — Network-sold CPM/CPC ad; reference model: CPM on unique opens or CPC.
- **F3.A.6 Community channel post** — Sponsored post in Slack, Discord or Skool; reference model: Monthly flat fee.

### F3.B Audio & video media

- **F3.B.1 Podcast host-read ad (mid-roll)** — Host reads the sponsor spot, baked-in or recorded; reference model: CPM.
- **F3.B.2 Podcast pre-roll / post-roll** — Spot at start or end; reference model: CPM.
- **F3.B.3 Podcast programmatic / DAI** — Dynamically inserted spots; reference model: CPM.
- **F3.B.4 YouTube long-form integration** — 60-90s mid-roll read in a video; reference model: CPM on expected views or flat.
- **F3.B.5 YouTube dedicated video** — Whole video about the sponsor; reference model: Multiple of integration.
- **F3.B.6 Radio / local broadcast spot** — Terrestrial radio spot or sponsorship; reference model: Per spot / CPM.

### F3.C Event sponsorships

- **F3.C.1 Title / presenting sponsor** — Top tier with naming; reference model: Flat package.
- **F3.C.2 Tiered package (Gold/Silver/Bronze)** — Standard tier bundles; reference model: Flat package.
- **F3.C.3 Exhibitor / booth (trade show)** — Floor space; reference model: Space + logistics.
- **F3.C.4 Session / track / keynote sponsorship** — Paid stage time; reference model: Flat, often inside a tier.
- **F3.C.5 Meals / reception / happy hour** — Catering naming; reference model: Flat.
- **F3.C.6 Swag / lanyard / badge / wifi / app item** — Branded utility items; reference model: Flat.
- **F3.C.7 Lounge / hub** — Branded space; reference model: Flat.
- **F3.C.8 Attendee-list / lead-retrieval** — Paid access to opt-in leads; reference model: Flat or per lead.
- **F3.C.9 Virtual summit sponsor** — Tier on an online summit; reference model: Flat tier.
- **F3.C.10 Webinar sponsor** — Paid slot in a publisher's webinar series; reference model: Flat or CPL.
- **F3.C.11 Meetup / local event sponsor** — Food, venue or cash for local meetups; reference model: In-kind or small flat.

### F3.D Content sponsorships

- **F3.D.1 Sponsored research / benchmark report** — Sponsor funds, publisher brands the report; reference model: Flat + leads.
- **F3.D.2 Sponsored tool / calculator / template** — Branded utility in a publisher property; reference model: Flat.
- **F3.D.3 Native / branded article (advertorial)** — Publisher-written, labeled sponsored; reference model: Flat.
- **F3.D.4 Sponsored series / season** — Sponsor owns a season or vertical; reference model: Flat package.
- **F3.D.5 Naming rights** — Name on event, stage, award or channel; reference model: Flat.
- **F3.D.6 Sponsored awards / lists** — Sponsor funds an award or ranking; reference model: Flat.

### F3.E Sports & local community sponsorships

- **F3.E.1 Youth team / league** — Jersey, banner or league naming; reference model: Per season.
- **F3.E.2 School events / boosters** — Booster clubs, yearbook, scoreboard; reference model: Per season.
- **F3.E.3 Church / community festival** — Festival booths and banners; reference model: Flat.
- **F3.E.4 Charity gala / golf / 5K sponsor (cause overlap)** — Flat-fee visibility at a charity event; reference model: Flat.
- **F3.E.5 Minor-league / semi-pro signage & promo nights** — Signage, promo nights; reference model: Flat.
- **F3.E.6 Stadium / arena signage & naming rights** — Enterprise sports inventory; reference model: Multi-year contract.

## F4 Co-Promotion — 38 types

Co-Promotion is two or more businesses jointly promoting an event, offer or content piece to their combined audiences.

### F4.A Joint events

- **F4.A.1 Co-hosted webinar** — Both brands on the page, both mail, leads shared; reference model: 50/50 of net sales or 30-50% to the non-owner (inferred).
- **F4.A.2 Joint workshop / masterclass** — Paid or free joint training with a joint offer; reference model: Revenue split.
- **F4.A.3 Virtual summit co-host / co-producer** — Co-owns the summit, list and pass revenue; reference model: Shared pass revenue and list.
- **F4.A.4 Summit speaker-promoter** — Speaker who contractually promotes for a pass-sales share; reference model: 40-50% affiliate on pass sales.
- **F4.A.5 Co-hosted challenge** — Multi-day challenge run by two experts; reference model: Split upsell revenue.
- **F4.A.6 Joint in-person event / seminar / roadshow** — Split venue and ad costs, shared attendee list; reference model: Cost and revenue split.
- **F4.A.7 Co-hosted live audio / video** — X Spaces co-hosts, LinkedIn Live co-organizers, collab Lives; reference model: Shared leads.
- **F4.A.8 Joint podcast crossover episode** — Both shows publish the same recorded conversation; reference model: Shared audience exposure.
- **F4.A.9 Webinar swap: guest on theirs (with split)** — You present to their list; they earn commission or reciprocity; reference model: Commission or reciprocal promotion.
- **F4.A.10 Webinar swap: host them on yours** — They present to your list; you earn commission; reference model: Commission.

### F4.B Joint launches & offers

- **F4.B.1 JV launch partner** — List owners mail during a launch window, with leaderboards and prizes; reference model: 30-50% commission; $100 minimum in high-ticket.
- **F4.B.2 JV launch manager / broker** — Third party recruits and runs the partner team; reference model: Retainer + about 10% of launch revenue.
- **F4.B.3 Bundle sale** — Many contributors' products sold at one price for 48 hours to 5 days; reference model: Affiliates 50-65%; contributors 70-80% on own sales.
- **F4.B.4 Co-sponsored giveaway / loop giveaway** — Pooled prizes; entrants opt in to all partners; reference model: Shared list.
- **F4.B.5 Seasonal joint promotion** — Black Friday cross-offers, joint gift guides; reference model: Cross-traffic.
- **F4.B.6 Joint packaged offer (single campaign)** — Two complementary services sold together at one price for one campaign; reference model: Revenue split.

### F4.C Content co-marketing

- **F4.C.1 Co-authored ebook / report / research** — Joint content with shared lead capture; reference model: Shared leads.
- **F4.C.2 Joint case study** — One customer shared by two vendors; reference model: Shared exposure.
- **F4.C.3 Guest post swap** — Reciprocal guest articles; reference model: Reciprocal.
- **F4.C.4 Co-branded tool / template / calculator** — Jointly branded utility; reference model: Shared leads.
- **F4.C.5 Co-produced video / interview series** — Jointly produced series; reference model: Shared exposure.
- **F4.C.6 Co-authored lead magnet (split capture)** — One asset, both capture leads; reference model: Shared leads with named-partner consent.

### F4.D Audience & list swaps

- **F4.D.1 Newsletter swap** — Reciprocal mention or dedicated send; reference model: Reciprocal.
- **F4.D.2 Free recommendation network** — beehiiv Recommendations, Substack Recommendations, Kit Creator Network; reference model: Reciprocal.
- **F4.D.3 Paid CPA recommendation (adjacent)** — beehiiv Boosts, SparkLoop, Kit paid recommendations; reference model: CPA.
- **F4.D.4 Podcast feed swap** — Each show publishes the other's full episode in its own feed; reference model: Reciprocal.
- **F4.D.5 Podcast promo / trailer swap** — Recorded or host-read promo swaps; reference model: Reciprocal.
- **F4.D.6 Social collab post / shoutout swap** — IG Collab posts, co-authored LinkedIn posts; reference model: Reciprocal.
- **F4.D.7 Post-purchase / thank-you page cross-offer** — Each partner's offer on the other's confirmation page; reference model: Reciprocal or commission.

### F4.E Local & retail cross-promotion

- **F4.E.1 Co-branded coupon / offer** — Buy at A, get a discount at B; reference model: Cross-traffic.
- **F4.E.2 Shared loyalty / punch card / passport** — Points or stamps across partners; reference model: Cross-traffic.
- **F4.E.3 Shop-local / district campaign** — BID- or chamber-led campaign; reference model: Shared cost.
- **F4.E.4 In-store cross-merchandising / co-display** — Shared endcap or display; reference model: Cross-sales.
- **F4.E.5 Jointly funded local advertising** — Shared billboard, mailer or radio buy; reference model: Cost split.
- **F4.E.6 Jointly hosted community event** — Tournaments, demos, markets; reference model: Shared leads.

### F4.F B2B tech-partner co-marketing

- **F4.F.1 Integration-partner joint campaign** — Joint webinar, content or booth between integration partners; reference model: Shared leads.
- **F4.F.2 Account-mapping joint campaign** — Campaign aimed at overlapping accounts found through Crossbeam or Reveal; reference model: Shared pipeline.
- **F4.F.3 Peer co-funded campaign** — Two peers split the campaign budget; reference model: Cost split.

## F5 Stages & Media — 48 types

Stages & Media is earned or arranged exposure where you appear as a guest, speaker, expert or source on a platform someone else owns.

### F5.A Audio

- **F5.A.1 Interview-show guest** — 1:1 host interview; the core type; reference model: Unpaid; exposure.
- **F5.A.2 Panel / roundtable guest** — Multi-guest show; reference model: Unpaid.
- **F5.A.3 Guest segment on solo / news show** — Expert call-in, expert of the week; reference model: Unpaid.
- **F5.A.4 Podcast tour** — Launch-timed burst of 10-50 appearances; reference model: Unpaid; booked via agency.
- **F5.A.5 Podcast guest swap** — You guest on theirs, they guest on yours; reference model: Reciprocal.
- **F5.A.6 Radio guest / radio media tour** — Talk-radio, satellite, RMT; reference model: Unpaid.
- **F5.A.7 Live audio room** — X Spaces speaker or co-host; reference model: Unpaid.
- **F5.A.8 Pay-for-play sponsored guest (hybrid)** — You pay the host to appear as a guest; reference model: Guest pays host; must disclose.

### F5.B Video & new media

- **F5.B.1 YouTube interview guest** — Interview on the host's channel; reference model: Unpaid.
- **F5.B.2 YouTube guest-style collab** — Guest appearance with a creator; reference model: Unpaid.
- **F5.B.3 Livestream guest** — YouTube Live, Twitch, Rumble; reference model: Unpaid.
- **F5.B.4 LinkedIn Live guest** — Guest or speaker on a host's LinkedIn Live; reference model: Unpaid.
- **F5.B.5 TikTok / Instagram Live collab** — Dual-screen live; reference model: Unpaid.
- **F5.B.6 Streaming show / digital network guest** — FAST channels, business streaming shows; reference model: Unpaid.
- **F5.B.7 Local TV segment** — Morning show or news commentary; reference model: Unpaid.

### F5.C Conference & industry stages

- **F5.C.1 Keynote** — Main-stage talk; reference model: Fee (or comp).
- **F5.C.2 Breakout session** — Track session; reference model: Usually unpaid.
- **F5.C.3 Panel** — Moderated panel seat; reference model: Usually unpaid.
- **F5.C.4 Workshop / pre-conference intensive** — Half- or full-day session; reference model: Honorarium or fee.
- **F5.C.5 Fireside chat** — Moderated Q&A; reference model: Fee.
- **F5.C.6 Demo-theater / floor-stage talk** — Expo-floor talk, often sponsor-bought; reference model: Often pay-to-speak (hybrid with [[F3 Sponsorships|F3]]).
- **F5.C.7 Lightning / poster talk** — Short-format session; reference model: Unpaid.
- **F5.C.8 Association chapter / CE-credit session** — Chapter meeting or CE session; reference model: Unpaid or honorarium.

### F5.D Local, civic, education & corporate stages

- **F5.D.1 Chamber of Commerce lunch talk** — Member lunch presentation; reference model: Unpaid.
- **F5.D.2 Civic club talk** — Rotary, Kiwanis, Lions; reference model: Unpaid.
- **F5.D.3 Networking-group feature talk** — BNI or leads-group feature presentation; reference model: Unpaid.
- **F5.D.4 Library / SBDC / SCORE workshop** — Free public small-business workshop; reference model: Unpaid or small fee.
- **F5.D.5 Church / community group talk** — Community education session; reference model: Unpaid.
- **F5.D.6 University guest lecture** — Business school or class lecture; reference model: Unpaid.
- **F5.D.7 Accelerator / incubator judge or office hours** — Demo-day judge, mentor slots; reference model: Unpaid.
- **F5.D.8 Corporate lunch-and-learn / training / SKO** — In-house session; reference model: Often paid.
- **F5.D.9 Practice stage** — Toastmasters, open mics, pitch nights; reference model: Unpaid.

### F5.E Virtual stages

- **F5.E.1 Virtual summit speaker** — Recorded or live talk with no promotion obligation; reference model: Unpaid, or optional affiliate link.
- **F5.E.2 Guest on a host's webinar** — Host owns the list; reference model: Unpaid.
- **F5.E.3 Bundled webinar-series presenter** — One of many presenters in a series; reference model: Unpaid.
- **F5.E.4 Online conference session** — Session at a virtual conference; reference model: Unpaid or fee.

### F5.F Seminars & expert rooms

- **F5.F.1 Guest presenter at a promoter's seminar (platform selling)** — Sell a program from a promoter's stage; reference model: Split of sales with promoter.
- **F5.F.2 Mastermind guest expert** — Guest session inside a mastermind; reference model: Unpaid or fee.
- **F5.F.3 Bootcamp / retreat guest trainer** — Guest session at a bootcamp or retreat; reference model: Fee or comp.
- **F5.F.4 Paid-community expert call (one-off)** — One expert call in someone's paid group; reference model: Unpaid, lead-share.

### F5.G Earned media & PR

- **F5.G.1 Expert quote / commentary** — Source in articles via query marketplaces; reference model: Unpaid; tool fee.
- **F5.G.2 Bylined article / guest column** — Authored piece in an outlet; reference model: Unpaid (paid councils are hybrid).
- **F5.G.3 Guest blog post** — Post on a host blog; reference model: Unpaid.
- **F5.G.4 Newsletter guest essay** — Guest issue in a host newsletter; reference model: Unpaid.
- **F5.G.5 Awards / "40 under 40" lists** — Recognition lists (many pay-to-enter); reference model: Entry fee sometimes.
- **F5.G.6 Feature / profile subject** — Outlet profiles you; reference model: Unpaid.
- **F5.G.7 Book / anthology / report inclusion** — Contributor to someone else's publication; reference model: Unpaid or fee.
- **F5.G.8 Roundup / listicle inclusion** — Named in expert roundups; reference model: Unpaid.

## F6 Referral & Power Partners — 26 types

Referral & Power Partners are businesses and professionals who already serve your buyers and send you specific named introductions, or endorse your offer to their customers.

### F6.A Referral partners

- **F6.A.1 One-way paid referral (finder's fee)** — Partner sends leads; you pay per lead, close or %; reference model: Flat or % of first sale / first year.
- **F6.A.2 Reciprocal referral** — Two firms trade clients with no money; reference model: Traded leads.
- **F6.A.3 Referral network / group** — One seat per trade (BNI, leads clubs, referral circles); reference model: Membership dues.
- **F6.A.4 Strategic referral alliance** — Written referral agreement with SLAs; reference model: Fee, rev share or reciprocal.
- **F6.A.5 Lead swap / lead-sharing agreement** — Exchange leads that don't fit; reference model: Even swap or per-lead price.
- **F6.A.6 Competitor overflow / pass-over** — Send work you can't take to a competitor for a fee; reference model: Referral fee or reciprocal.

### F6.B Lifecycle handoff partners

- **F6.B.1 Before (upstream) partner** — Sells to the customer before they need you; reference model: As [[F6.A Referral partners|F6.A]].
- **F6.B.2 During (concurrent) partner** — Bought at the same time as you; reference model: As [[F6.A Referral partners|F6.A]].
- **F6.B.3 After (downstream) partner** — Bought after you; reference model: As [[F6.A Referral partners|F6.A]].
- **F6.B.4 Instead-of (substitute) partner** — What customers buy when they don't buy you; reference model: As [[F6.A Referral partners|F6.A]].

### F6.C Endorsed JVs (host-beneficiary)

- **F6.C.1 Endorsed mailing / email** — Host mails their list recommending your offer under the host's name; reference model: Commonly 50/50 of profit; Abraham cites 10-90% splits.
- **F6.C.2 Insert / package stuffer / invoice JV** — Your offer rides in the host's shipments or invoices; reference model: Per-insert fee or rev share.
- **F6.C.3 Endorsed webinar / event** — Host invites their audience to your webinar; reference model: Rev share.

### F6.D Offer JVs

- **F6.D.1 Back-end JV** — Partner's product offered to your buyers after purchase; reference model: Rev share, 25-50% to host (inferred).
- **F6.D.2 Front-end JV / lead-offer swap** — Partner's free or low-cost offer used as your acquisition bait; reference model: Rev share.
- **F6.D.3 Bundle / package JV** — Ongoing joint offer at one price; reference model: Split.
- **F6.D.4 Consignment / pay-on-sale** — Product placed with a host who pays only on sale; reference model: Host margin.

### F6.E Resource JVs

- **F6.E.1 Sales-force leasing** — Borrow a partner's reps; reference model: Fixed rate + override on residuals.
- **F6.E.2 Fulfillment / capacity JV** — Partner delivers work you sell; reference model: Results-based share.
- **F6.E.3 R&D-for-share** — Partner builds in exchange for a revenue share; reference model: Rev share.
- **F6.E.4 Call-center / telemarketing share** — Borrow a partner's calling capacity; reference model: Per result.

### F6.F Asset deals

- **F6.F.1 Dormant-list reactivation JV** — Your offer to a partner's inactive customers; reference model: Revenue split.
- **F6.F.2 Idle brand / product / IP revival** — Relaunch an unused asset; reference model: Split.
- **F6.F.3 Idle space / equipment / inventory** — Share idle capacity; reference model: Cost or revenue split.

### F6.G Gap & orchestrator JVs

- **F6.G.1 Gap / arbitrage JV** — Combine assets no one has combined; reference model: Orchestrator-heavy split.
- **F6.G.2 Orchestrator / JV broker** — Match two parties and take an override; reference model: Override.

## F7 Access Partners — 31 types

Access Partners are organizations that own a group your buyers already belong to: members, franchisees, employees, community members or attendees.

### F7.A Institutions & associations

- **F7.A.1 Trade association affinity program** — Member discount or endorsed-vendor status; reference model: Royalty and/or services fee.
- **F7.A.2 Professional association / licensing body** — CPA, bar or realtor board member benefit; reference model: Royalty + member discount.
- **F7.A.3 Chamber of commerce partner program** — Member perk or preferred vendor; reference model: Flat or royalty.
- **F7.A.4 Economic development org / SBDC** — Access to small-business clients; reference model: Usually in-kind.
- **F7.A.5 Industry council** — Council member offers; reference model: Flat or royalty.
- **F7.A.6 Union member-benefit program** — Member benefit offers; reference model: Royalty.
- **F7.A.7 Alumni association / university** — Alumni perks, career services, incubators; reference model: Royalty or flat.
- **F7.A.8 Credit union / community bank member offer** — Business-member perks; reference model: Rev share.

### F7.B Buying & operating networks

- **F7.B.1 Franchisor preferred / approved vendor** — Vendor listed or mandated for all units; reference model: Volume rebate to franchisor.
- **F7.B.2 GPO / buying group** — Contracted vendor to pooled buyers; reference model: Admin fee % of purchases.
- **F7.B.3 Purchasing / marketing co-op** — Vendor to a member co-op; reference model: Admin fee or rebate.
- **F7.B.4 Dealer council** — Vendor to a dealer network's council; reference model: Rebate.
- **F7.B.5 PE portfolio platform** — Portfolio-wide vendor deal; reference model: Negotiated.
- **F7.B.6 Property manager / landlord tenant perk** — Tenant offers; reference model: Rev share or flat.

### F7.C Employer & benefit platforms

- **F7.C.1 Employee perks marketplace** — Vendor listed in perk catalogs; reference model: Merchant-funded commission.
- **F7.C.2 Benefits broker / PEO** — Vendor offered through benefits channels; reference model: Commission.
- **F7.C.3 Rewards / recognition platform** — Vendor inside reward catalogs; reference model: Commission.

### F7.D Communities & memberships

- **F7.D.1 Paid community member perk** — Offer in a Skool, Circle or Mighty "perks" tab; reference model: Rev share.
- **F7.D.2 Facebook / LinkedIn group partner** — Standing offer in a group; reference model: Rev share or flat.
- **F7.D.3 Slack / Discord community partner** — Standing partner status; reference model: Rev share or flat.
- **F7.D.4 Mastermind / peer group vendor** — Introduced to all members; reference model: Rev share.

### F7.E Event & room owners

- **F7.E.1 Conference attendee-offer partner** — Standing offer to all attendees; reference model: Rev share.
- **F7.E.2 Trade show organizer partner** — Organizer-endorsed solution provider; reference model: Rev share.
- **F7.E.3 Meetup / networking host** — Host introduces you to the group on a standing basis; reference model: Rev share or finder's fee.
- **F7.E.4 Workshop / retreat operator** — Offer to every cohort; reference model: Rev share.
- **F7.E.5 Webinar-series host** — Standing offer across a host's series; reference model: Rev share.

### F7.F Connectors & gatekeepers

- **F7.F.1 Coach / consultant client book** — Introduces you to their whole client roster; reference model: Rev share.
- **F7.F.2 Business broker** — Access to buyers and sellers they represent; reference model: Finder's fee.
- **F7.F.3 Fractional executive portfolio** — Fractional CFO or CMO across clients; reference model: Rev share.
- **F7.F.4 Accountant / attorney advisory base** — Advisor opens the client base; reference model: Flat or services fee (check professional rules).
- **F7.F.5 Finder (group introduction)** — Unlicensed finder opening a group; reference model: Finder's fee.

## F8 Channel Partners — 25 types

Channel Partners are third parties who resell, deliver, embed or distribute your offer.

### F8.A Resell & distribute

- **F8.A.1 Reseller / authorized dealer** — Buys and resells; reference model: Discount margin.
- **F8.A.2 VAR** — Reseller adding services; reference model: Margin.
- **F8.A.3 Distributor / aggregator** — Wholesale to resellers; reference model: Margin.
- **F8.A.4 TSD / master agent + technology advisor** — Distributor with advisors (agents) under it; reference model: Recurring residuals.
- **F8.A.5 ISO / sub-ISO / merchant-services agent** — Card-processing sales agents; reference model: Residual split.
- **F8.A.6 Funding / loan broker ISO** — Sells lending products (MCA, SBA); reference model: Points or commission.
- **F8.A.7 Independent sales rep / manufacturer's rep** — 1099 commission-only rep; reference model: Commission.
- **F8.A.8 Dealer network** — Local dealers selling your product; reference model: Margin.

### F8.B Deliver & manage

- **F8.B.1 MSP** — Managed service provider bundling you; reference model: Margin + services.
- **F8.B.2 MSSP** — Managed security provider; reference model: Margin + services.
- **F8.B.3 System integrator / GSI** — Large-scale implementation; reference model: Services revenue.
- **F8.B.4 Implementation / solutions partner** — Certified implementers; reference model: Rev share on sourced MRR + services.
- **F8.B.5 Consultancy / fractional operator** — Advisors who deliver and resell; reference model: Services + margin.
- **F8.B.6 Implementation agency partner** — Agency that deploys your product for its clients; reference model: Services + rev share.

### F8.C Embed & integrate

- **F8.C.1 ISV / technology partner** — Integration + co-sell; reference model: Co-sell pipeline.
- **F8.C.2 OEM / embedded** — Your product inside theirs under their SKU; reference model: Royalty per seat/unit.
- **F8.C.3 Platform-built app** — App built on a host platform; reference model: Platform take rate.
- **F8.C.4 API / data partner** — Data or API supply; reference model: Usage fees.

### F8.D Marketplaces

- **F8.D.1 Hyperscaler marketplace (incl. CPPO)** — AWS, Azure or GCP listing; resellers transact via private offers; reference model: Take rate.
- **F8.D.2 SaaS app marketplace** — HubSpot, AppExchange, GHL, Shopify, Zapier, Atlassian; reference model: Take rate.
- **F8.D.3 Vertical marketplace** — Industry-specific marketplace; reference model: Take rate.
- **F8.D.4 Info-product / community marketplace** — ClickBank, Skool Discovery, Whop; reference model: Take rate + affiliate pay.

### F8.E White-label & rebrand resale

- **F8.E.1 White-label SaaS reseller** — Partner resells your software under their brand; reference model: Markup.
- **F8.E.2 White-label fulfilment reseller** — Partner resells your service under their brand; reference model: Markup.
- **F8.E.3 Private-label course / certification reseller** — Partner resells your finished course as theirs; reference model: Wholesale price or rev share.

## F9 Strategic Alliances & Licensing — 27 types

Strategic Alliances & Licensing are long-term contractual or equity arrangements that share intellectual property, brand, method, territory, ownership or operations, beyond any single campaign or sale.

### F9.A Co-branding & co-created products

- **F9.A.1 Co-branded offer** — Two brands on one ongoing product; reference model: Margin split or royalty.
- **F9.A.2 Ingredient branding** — Partner's brand as a named component; reference model: Co-op marketing funds.
- **F9.A.3 Co-developed product** — Jointly built product with shared IP; reference model: Rev share by contribution.
- **F9.A.4 Private-label product sourcing** — Made to your spec, sold only under your brand; reference model: Wholesale margin.

### F9.B Licensing

- **F9.B.1 Brand / trademark licensing** — Licensee uses your name on their products; reference model: Royalty on wholesale.
- **F9.B.2 Technology / patent licensing** — License software, patents or methods; reference model: % of net sales.
- **F9.B.3 Content / curriculum / IP licensing** — License a course, framework or certification; reference model: Per-seat or rev share.
- **F9.B.4 Character / personality licensing** — A person's name or likeness; reference model: Royalty + advance.
- **F9.B.5 Sublicensing / master license** — Licensee re-licenses to others; reference model: Share of sublicense income.

### F9.C Franchise-style & licensed-operator models

- **F9.C.1 Franchise (FTC-regulated)** — Trademark + significant control + required payment of $735+; reference model: Royalty on gross.
- **F9.C.2 Licensed operator / certification program** — Use of a method or name without significant control; reference model: License fee or rev share.
- **F9.C.3 Dealer / territory rights** — Exclusive rights in a territory; reference model: Fee + royalty.
- **F9.C.4 Area developer / master franchise** — Develops multiple units in a region; reference model: Fee + override.

### F9.D Equity & contractual JVs

- **F9.D.1 Equity joint venture** — New jointly owned entity; reference model: Equity split.
- **F9.D.2 Minority-stake alliance** — One partner takes a stake in the other; reference model: Equity.
- **F9.D.3 Contractual (non-equity) JV** — Contract-only long-term venture; reference model: Profit split.
- **F9.D.4 Earn-in deal** — Partner earns equity by hitting milestones; reference model: Equity vesting.
- **F9.D.5 Rev-share-for-equity swap** — Revenue share converted to equity; reference model: Equity.

### F9.E Purchasing co-ops & group buying (as organizer)

- **F9.E.1 Purchasing co-op / GPO formation** — Members pool volume for discounts; reference model: Vendor admin fees.
- **F9.E.2 Community group-buying deal** — Negotiated volume discount for a community; reference model: Admin fee or goodwill.

### F9.F Shared services & resource alliances

- **F9.F.1 Shared staff / office / back office** — Ongoing shared operations; reference model: Cost split.
- **F9.F.2 Teaming agreement / joint bid** — Joint bids, e.g. government contracts; reference model: Work share.
- **F9.F.3 Exclusive distribution rights** — Secure exclusive rights to distribute a product; reference model: Margin.

### F9.G R&D & innovation partnerships

- **F9.G.1 Joint R&D** — Co-funded development; reference model: Shared IP.
- **F9.G.2 Sponsored university research** — Firm funds academic research; reference model: Funding for IP rights.
- **F9.G.3 Design partner / pilot program** — Early customers co-shape the product; reference model: Discount for input.
- **F9.G.4 Data partnership** — Share or pool data assets; reference model: Data access.

## F10 Cause & Nonprofit Partners — 15 types

Cause & Nonprofit Partners are charities, schools, teams, faith and civic groups where the business's contribution (a percentage of sales, a donation per unit, a fundraiser share or in-kind support) produces revenue, traffic or community access in return.

### F10.A Cause marketing

- **F10.A.1 Percent-of-sale / $-per-unit** — Fixed share of each purchase donated during a campaign; reference model: Donation from margin.
- **F10.A.2 Buy-one-give-one / in-kind** — Product or service donated per sale; reference model: In-kind cost.
- **F10.A.3 Checkout / round-up ask** — Customer donates at checkout; reference model: Customer money passes through.
- **F10.A.4 Cause-branded product** — Special edition supporting a cause; reference model: Rev share to charity.
- **F10.A.5 Cause affiliate** — Nonprofit promotes via a tracked link and earns a donation per sale; reference model: % of sale as donation.

### F10.B Community fundraisers & charity events

- **F10.B.1 Spirit / fundraiser night** — Group brings its people; business donates a share of the night's sales; reference model: % of qualifying sales.
- **F10.B.2 Product fundraiser / gift-card resale** — Group sells your product or cards at a margin; reference model: Group margin.
- **F10.B.3 Fundraiser service partnership** — You run the fundraiser with the nonprofit; reference model: Shared entry and sponsor revenue.
- **F10.B.4 Charity auction / in-kind event donor** — Donate a package to a gala or auction; reference model: Leads from winners.

### F10.C Pledges & certifications

- **F10.C.1 Percent-of-revenue pledge** — Ongoing pledge such as 1% for the Planet or Pledge 1%; reference model: At least 1% of annual sales.
- **F10.C.2 B Corp / benefit corporation** — Third-party certification or legal form; reference model: Certification cost; B Corp buyer networks.

### F10.D Community & institutional partnerships

- **F10.D.1 School / workforce partnership** — Internships, apprenticeships, curriculum; reference model: Talent pipeline; possible curriculum fee.
- **F10.D.2 Faith / civic community partnership** — Member discount through churches or civic groups; reference model: Discount as referral channel.
- **F10.D.3 Nonprofit referral program** — Nonprofit refers members; business donates per job; reference model: Donation per referred customer.
- **F10.D.4 Employee volunteering / gift matching** — Company matches staff gifts or time; reference model: Retention and PR.

## F11 House Partners — 29 types

House Partners are the business's own base: customers, past buyers, old leads, employees, contractors and alumni.

### F11.A Customer referral

- **F11.A.1 Refer-a-friend (give/get)** — Single- or double-sided rewards; reference model: Credit, cash or discount.
- **F11.A.2 B2B customer referral program** — Account credits, cash or charity donation for referrals; reference model: Credit or cash.
- **F11.A.3 Referral contest** — Time-boxed prizes for most referrals; reference model: Prizes.
- **F11.A.4 Gifted seat / trial** — Customers gift access to peers; reference model: Product.

### F11.B Advocacy & proof

- **F11.B.1 Customer ambassador / advocate** — Superfans promoting with perks; reference model: Points, perks, swag.
- **F11.B.2 Customer advisory board** — Customers shaping the roadmap; reference model: Access, recognition.
- **F11.B.3 Case-study partner** — Customer featured in a story; reference model: Recognition, discount.
- **F11.B.4 Reference customer** — Takes sales calls for you; reference model: Credit, perks.
- **F11.B.5 Review generator** — Reviews on Google, G2, Capterra; reference model: None (incentives restricted).
- **F11.B.6 Testimonial / UGC contributor** — Customer-created proof content; reference model: Perks.
- **F11.B.7 User-group champion / community MVP** — Runs user groups or leads the community; reference model: Recognition, access.
- **F11.B.8 Customer speaker** — Customer on your stage or webinar; reference model: Recognition.

### F11.C Loyalty & expansion

- **F11.C.1 Loyalty / points program** — Points for purchases and actions; reference model: Points.
- **F11.C.2 VIP tier** — Status tiers with perks; reference model: Perks.
- **F11.C.3 Upsell / cross-sell / ascension ladder** — Move buyers up the offer ladder; reference model: Offer pricing.
- **F11.C.4 Multi-location / account expansion** — Expand into new sites or departments; reference model: Offer pricing.
- **F11.C.5 Customer-to-partner conversion** — Customer becomes affiliate, reseller or implementer; reference model: Hand-off to [[F1 Affiliates|F1]], [[F8 Channel Partners|F8]] or [[F9 Strategic Alliances & Licensing|F9]].

### F11.D Reactivation & win-back

- **F11.D.1 Dormant-lead database reactivation** — SMS, email or AI calling to old leads; reference model: Offer.
- **F11.D.2 Past-buyer reactivation** — Re-offer to past buyers; reference model: Offer.
- **F11.D.3 Lapsed-subscription win-back** — Win back cancelled subscribers; reference model: Discount.
- **F11.D.4 Failed-payment / involuntary-churn recovery** — Dunning and card retries; reference model: None.
- **F11.D.5 Pause-instead-of-cancel** — Offer a pause at cancellation; reference model: Pause.
- **F11.D.6 No-show / unclosed-proposal follow-up** — Revive stalled pipeline; reference model: Offer.
- **F11.D.7 Churned-to-competitor win-back** — Target customers lost to rivals; reference model: Discount.

### F11.E Team & network

- **F11.E.1 Employee hiring referral** — Staff refer hires; reference model: Bonus, often in installments.
- **F11.E.2 Employee sales referral** — Staff refer customers; reference model: Spiff.
- **F11.E.3 Employee advocacy** — Staff share brand content; reference model: Recognition.
- **F11.E.4 Boomerang alumni network** — Former staff as referrers and rehires; reference model: Bonus.
- **F11.E.5 Placed contractors / VAs** — VAs placed with clients refer new clients; reference model: Bonus.
